# LxPilot

Нативный клиент macOS (SwiftUI) для ядра [sing-box-lx](https://github.com/Leadaxe/sing-box-lx): боковая навигация, панель из карточек, группы прокси плиткой, значок со скоростью в строке меню.

> Статус: v0.1, ранняя версия. Интерфейс только на русском, тестов нет. Что проверено на живом Mac, а что нет — в разделе «Ограничения».

## Установка

Нужна macOS 26 или новее (Apple silicon или Intel).

1. Скачайте `LxPilot-<версия>.dmg` со страницы [релизов](../../releases/latest) и перетащите приложение в «Программы».
2. Сборка подписана ad-hoc и не нотаризована, поэтому Gatekeeper её не пустит. Снимите карантин:

   ```sh
   xattr -dr com.apple.quarantine /Applications/LxPilot.app
   ```

3. Сверить файл можно по `SHA256SUMS` из того же релиза: `shasum -a 256 -c SHA256SUMS`.

Приложение живёт в строке меню и не показывается в Dock: клик по значку открывает окно, правый клик — меню.

## Первый запуск

1. **Инструменты → Скачать последний релиз** — приложение берёт `sing-box-…-darwin-arm64/amd64.tar.gz` из релизов Leadaxe/sing-box-lx, сверяет с `SHA256SUMS` и кладёт бинарь в `~/Library/Application Support/LxPilot/bin/`. Можно указать свой файл.
2. **Профили → Добавить** — URL подписки, готовый конфиг sing-box (JSON, допускаются комментарии) или ссылки `vless://`, `trojan://`, `ss://`, `hysteria2://`.
3. Кнопка «Старт» в окне или в поповере значка.

## Что умеет

| Раздел | Содержимое |
| --- | --- |
| Панель | график скорости, режим маршрутизации, трафик за сеанс, переключатели TUN и системного прокси, текущий узел с внешним IP и задержкой |
| Прокси | группы selector/urltest, выбор узла, проверка задержки; для профиля без групп селектор создаётся автоматически |
| Маршруты | свои правила поверх профиля и переключаемые сценарии, наборы правил, просмотр и импорт правил профиля |
| Приложения | принудительный маршрут по процессу: через прокси или напрямую |
| Сети | правила Wi-Fi: в одних сетях отключать VPN или вести всё напрямую, в других — включать |
| Профили | подписки с обновлением, остаток трафика и срок из `subscription-userinfo`, локальные конфиги |
| Соединения | таблица активных соединений с цепочкой и правилом, поиск, закрытие |
| Логи | поток лога ядра с фильтром по уровню и поиском |
| Инструменты | установка ядра, движок, порты, стек TUN, системная служба, автозапуск, тема и акцент |

Значок в строке меню показывает скорость и мини-графики (вид переключается), при наведении открывает поповер с графиком за 5 минут, узлом и самыми активными соединениями, а при сбое соединения мигает красным.

## Как устроено

- **Движок `lxd` (по умолчанию).** Ядро запускается как `sing-box lxd --state-dir … --config-force … --run` с каналом управления на `127.0.0.1` и случайным Bearer-секретом. Смена профиля и правил уходит в `POST /admin/apply`: демон проверяет конфиг и сам откатывается на last-good при сбое.
- **Движок `classic`.** Обычный `sing-box run`; любое изменение — перезапуск процесса.
- **Данные интерфейса** идут через Clash API ядра: приложение само вписывает в конфиг `experimental.clash_api` на `127.0.0.1` со случайным секретом.
- **Оверлей конфига.** Поверх профиля подставляются `clash_api`, `cache_file`, уровень логов, правила из разделов «Маршруты», «Приложения» и «Сети» и входящие: `mixed` на `127.0.0.1:7890` и, при включённом TUN, `tun`. Управление входящими отключается в «Инструментах».
- **TUN** требует root. Два способа: системный запрос пароля при каждом запуске или системная служба sing-box-lx (ставится из «Инструментов» один раз, дальше без пароля; приложение сопрягается с ней по mTLS).
- **Системный прокси** ставится через `networksetup` и снимается при отключении, выходе и при следующем запуске после аварийного завершения.

## Сборка из исходников

Нужны macOS 26+ и Xcode 26+ (Swift 6.2+). Сторонних зависимостей нет.

```sh
./build-app.sh                    # → build/LxPilot.app (ad-hoc подпись)
open build/LxPilot.app
```

Для разработки: `open Package.swift` (откроется в Xcode) или `swift run`.

Релизные файлы собирает `Tools/package-release.sh <версия>`: универсальный бинарь (arm64 + x86_64), `dist/LxPilot-<версия>.dmg`, `.zip` и `SHA256SUMS`.

## Выпуск релиза

Релиз собирает GitHub Actions ([release.yml](.github/workflows/release.yml)) по тегу:

```sh
git tag v0.2.0
git push origin v0.2.0
```

Тег с дефисом (`v0.2.0-rc.1`) публикуется как пре-релиз. Ручной запуск workflow собирает те же файлы и оставляет их артефактом, без релиза.

## Данные

`~/Library/Application Support/LxPilot/`: `bin/` (ядро), `profiles/`, `runtime/` (итоговый `config.json`, кэш), `lxd-user/` и `lxd-root/` (состояние и лог демона), `service/` (сертификат для системной службы), `settings.json`.

## Ограничения

- Проверено на живом Mac: движок lxd без TUN и с TUN через системную службу, системный прокси. Не проверено: движок `classic`, TUN через запрос пароля в свежих сборках, импорт подписок и ссылок целиком, правила Wi-Fi при настоящей смене сети.
- Правила Wi-Fi работают, только пока приложение запущено.
- Параметр `extra` в ссылках xhttp, ссылки и `.conf` WireGuard/AmneziaWG, `tuic://` и `vmess://` не разбираются — такие узлы добавляйте готовым JSON.
- Системная служба использует общую для sing-box-lx метку `com.leadaxe.sing-box-lxd`: она одна на систему и общая с другими клиентами этого ядра.
- При TUN через запрос пароля скрипт запуска от root лежит в папке, доступной пользователю на запись.
- Определение внешнего IP обращается к стороннему сервису ipwho.is.
